# 图片与视频「秒加载」方案

> 适用项目：陈庆.我爱你 / cos 私人图库  
> 存储：腾讯云 COS 私有桶 + 预签名  
> 当前示例桶：`cq-1327876314`，地域：`ap-hongkong`  
> 网站域名：中文域（可只托管网页，**不必**绑定 COS）

本文依据腾讯云 **对象存储 COS**、**数据万象 CI**、**内容分发网络 CDN** 的官方能力，说明如何让图库列表与详情在观感上接近「秒开」，同时 **原片仍可无损保存在 COS**。

---

## 排查：图片上传成功但全部加载失败（403 please use style）

COS/数据万象返回：

```text
AccessDenied — The image can not be accessed, please use style.
```

说明桶开启了 **原图保护**：浏览器签名 URL 必须带「图片样式」，裸对象或仅 `imageMogr2` 动态参数会被拒。

### 立刻恢复（推荐）

1. 打开 [腾讯云数据万象](https://console.cloud.tencent.com/ci) → 绑定你的桶  
2. **图片处理 → 原图保护 → 关闭**  
3. 强制刷新网站，图片应立即恢复（无需改代码）

### 若必须保留原图保护

1. 在数据万象创建样式，例如：  
   - `thumb`：`thumbnail/480x480>/format/jpg`  
   - `full`：接近原图或 `quality/90`  
2. 管理后台 COS 设置填写「列表缩略样式名 / 详情样式名」，或环境变量：  
   `COS_IMAGE_STYLE_THUMB=thumb`、`COS_IMAGE_STYLE_FULL=full`  
3. 签名会带 `style=<名>`（已纳入签名 Query）

### 1.1 「秒加载」分别指什么

| 场景 | 用户感知目标 | 技术手段 |
|------|--------------|----------|
| 图库网格 | 很快铺满缩略图 | 小图 + 缓存 + 懒加载 |
| 点开图片 | 立刻有画面，再变清晰 | thumb 占位 → 原图 |
| 视频格子 | 立刻有封面，不是灰块 | 持久化截帧海报 |
| 点开视频 | 尽快起播、可拖动进度 | 封面 + HTTP Range（+ CDN） |

**不是**把数百 MB 原视频在 1 秒内完整下载完毕。

### 1.2 必须遵守的架构原则

1. **列表禁止使用原图 / 整段视频 URL 铺格子**  
2. **原片上传仍走 COS 源站预签名 PUT**（不要用 CDN 域名上传）  
3. **中文网站域名不要填进 `COS_CDN_DOMAIN`**（绑不上或导致 PUT/GET 404）  
4. **私有桶 + 签名访问**；处理参数（缩略、截帧）需一并纳入签名  
5. 服务器 300Mbps 主要承载网页与 API；**媒体流量应走 COS/CDN**，不要经 Node 中转大文件（封面代理可例外且应限制）

### 1.3 推荐数据流

```textn用户浏览器
    │
    ├─ 网页 / API ──► 你的服务器（Next.js）
    │
    ├─ 缩略图 / 封面 GET（签名）──► CDN（英文域，长缓存）──► COS
    │
    ├─ 原图 / 原视频 GET（签名）──► CDN 或 COS 源站
    │
    └─ 上传 PUT（预签名）────────► COS 源站 only
```

## 2. 腾讯云侧能力对照

### 2.1 COS（对象存储）

- 私有读写桶，对象键统一 `media/` 前缀  
- 默认支持 **Range** 请求，利于视频拖动与边下边播  
- 上传：浏览器直传预签名 PUT，应用服务器不经手文件流  

### 2.2 数据万象 CI（图片 / 媒体处理）

| 能力 | 用途 | 典型参数或方式 |
|------|------|----------------|
| 图片缩放 / 转码 | 列表缩略图 | `imageMogr2/thumbnail/480x480>/format/webp` |
| 质量与格式 | 减小体积 | `quality/75`、`format/webp` |
| 样式 | 固定缩略规则 | `key!styleName` |
| 视频同步截帧 | 生成封面 | `ci-process=snapshot&time=1&format=jpg` |
| 媒体工作流 | 上传后自动截帧 | 控制台工作流，输出 poster 对象 |

说明：

- 私有对象：**签名 URL 后拼接处理参数**，且签名应覆盖处理参数，避免被去掉参数访问原图  
- 下载时处理会产生 **CI 处理费** 与可能的 **流量费**  
- 首次使用需桶绑定数据万象；视频截帧需开通相关媒体处理能力  

### 2.3 CDN

| 配置项 | 建议 |
|--------|------|
| 源站 | COS 源，选择对应桶 |
| 私有桶 | 授权 CDN，开启 **私有存储桶访问（回源鉴权）** |
| 加速域名 | **英文域名**（中文域常无法绑定） |
| 节点缓存 | 缩略图/封面 7～30 天；原图/视频可 7～30 天 |
| 分片回源 | 大视频建议开启（COS 支持 Range） |
| 视频拖拽 | 点播场景可开；注意与缓存键、参数规则一致 |
| 图片优化 | 源为 COS 时可开 WebP 等自适应（需 CI） |
| 用量封顶 | 建议开启，防刷流量 |

注意（官方常见说明）：

- 对 **大量实时图片处理** 的路径，分片回源可能影响回源行为，可按目录拆分策略  
- **PUT 上传不要走 CDN 域名**

## 3. 图片秒开详细方案

### 3.1 URL 设计

**列表（网格）**

```text
https://<CDN或COS主机>/<key>
  ?imageMogr2/thumbnail/480x480>/format/webp/quality/75
  &q-sign-algorithm=...（签名）
```

**详情原图**

```text
https://<主机>/<key>?<仅签名，无缩略参数>
```

实现要点（`lib/cos.ts`）：

- `getSignedUrl(key, expires, { thumb: true })` → 带 `imageMogr2/...`  
- `getSignedUrl(key, expires)` → 原图  
- 仅 **GET** 可替换为 CDN 主机；**PUT 禁止**替换  

### 3.2 前端行为

1. `/api/gallery` 返回的 `thumbUrl` 用于网格  
2. `loading="lazy"` + 固定 `aspect-square`，减少跳动  
3. 打开灯箱：先渲染 `thumbUrl`，再加载 `url` 原图，`onLoad` 后切换  
4. 失败时占位，避免空白  

### 3.3 控制台检查清单（图片）

- [ ] 桶已绑定数据万象  
- [ ] 私有读；CORS 允许网站 Origin（**无末尾 `/`**），方法含 GET/HEAD/PUT  
- [ ] 签名与处理参数联调通过（浏览器能打开 thumb URL）  
- [ ] （可选）CDN 图片优化 / WebP 自适应  

### 3.4 可选：上传时持久化缩略图

若希望减少「每次下载时处理」费用，可在上传时用 `Pic-Operations` 或云上数据处理生成 `*-thumb.webp` 并单独存对象。列表直接签该对象，不再实时 `imageMogr2`。

## 4. 视频秒开详细方案

### 4.1 为什么列表截帧会失败

前端对 iPhone **HEVC/MOV** 使用 `<video>` + `canvas` 截首帧，经常因解码、`seek`、代理超时失败，表现为 **灰块**。  
因此：**封面必须持久化**，不能只靠打开图库时现截。

### 4.2 官方同步截帧（生成封面）

```text
GET /<ObjectKey>?ci-process=snapshot&time=1&format=jpg
Host: <Bucket>-<APPID>.cos.<Region>.myqcloud.com
Authorization: <签名>
```

或 URL 查询参数形式。参数要点：

| 参数 | 说明 |
|------|------|
| `ci-process` | 固定 `snapshot` |
| `time` | 截帧时间点（秒），如 `1` 或 `0.1` |
| `format` | `jpg` / `png` |
| `width` / `height` | 可选，限制封面尺寸 |

**推荐用法：** 上传成功后由 **服务端任务** 调用一次截帧，把结果写入例如：

```text
media/2026/08/11/xxx-poster.jpg
```

数据库：

```text
Media.posterKey = "media/2026/08/11/xxx-poster.jpg"
```

图库只对 `posterKey` 做普通图片签名（可再加 `imageMogr2` 缩小）。

### 4.3 工作流异步截帧（更稳，适合批量）

1. 数据万象 / 媒体处理中创建 **视频截帧** 模板  
2. 工作流绑定前缀 `media/`  
3. 上传完成自动输出海报到固定命名规则  
4. 用回调或轮询把 `posterKey` 写回业务库  

适合存量视频补封面与 HEVC。

### 4.4 前端行为

| 位置 | 行为 |
|------|------|
| 网格 | 只显示 `posterUrl` 图片 + 时长角标 + ▶ |
| 禁止 | 列表 `preload="auto"` 多个大视频 |
| 详情 | 先显示海报；再设 `video.src`；用户点击进入后 `play()` |
| iOS | `playsInline`；自动播放可先 `muted`，再提供取消静音 |
| 拖动进度 | 依赖 Range；走 CDN 时开启分片回源更佳 |

### 4.5 控制台检查清单（视频）

- [ ] 已开通数据万象媒体处理 / 截帧  
- [ ] 同步截帧或工作流对样例 MOV/MP4 验证成功  
- [ ] 新上传写入 `posterKey`；旧数据可批量补  
- [ ] CDN 对视频路径启用分片回源（按需）

## 5. CDN 接入步骤（英文域）

### 5.1 为何需要英文域

中文域即使已备案，也经常 **无法绑定** COS 自定义域或 CDN。网页继续用中文域；媒体用英文 CDN 域。

### 5.2 步骤摘要

1. 准备英文域名并完成解析（CNAME 到 CDN）  
2. CDN 添加域名，源站类型 **COS**，选择 `cq-1327876314` 所在地域桶  
3. 私有桶：COS 授权 CDN，CDN 开启 **私有存储桶访问**  
4. HTTPS 证书配置  
5. 缓存：静态图片/封面长缓存；按需配置视频  
6. 防盗链：白名单网站域（中文域 + Punycode，Origin **不要**末尾 `/`）  
7. 用量封顶  
8. 项目配置 `COS_CDN_DOMAIN=cdn.your-english.com`（仅影响 **GET**）  
9. 确认上传 PUT 仍指向 `*.cos.ap-hongkong.myqcloud.com`  

### 5.3 预热与刷新

- 新热门封面/缩略图可 **预热**，减少首次回源  
- 同名覆盖更新后需 **刷新** CDN 缓存

## 6. 应用改造清单（本仓库）

### 6.1 后端

| 项 | 说明 |
|----|------|
| `getSignedUrl` thumb 规则 | 统一 `thumbnail` + `webp` + quality |
| GET 才使用 `cdnDomain` | PUT 永不换 host |
| `posterKey` | 上传后 CI 截帧或工作流回写 |
| `/api/gallery` | 图片 `thumbUrl`；视频 `posterUrl`/`thumbUrl` 来自海报 |
| 避免列表走 `cover-src` 拉整视频 | 仅作无海报时的降级，且应限流 |

### 6.2 前端

| 项 | 说明 |
|----|------|
| `MediaCover` | 优先 `posterUrl` / 图片 `thumbUrl` |
| 网格 | 懒加载，三列密铺 |
| `Lightbox` | 先小图后大图；视频进页再播 |
| 错误态 | 占位，禁止无意义蓝/灰空框 |

### 6.3 配置

```env
COS_BUCKET=cq-1327876314
COS_REGION=ap-hongkong
COS_SECRET_ID=...
COS_SECRET_KEY=...
# 仅英文 CDN 域；中文域或未接入时留空
COS_CDN_DOMAIN=
COS_THUMB_WIDTH=480
# 可选：展示链文字水印（无法防录屏）
COS_WATERMARK_ENABLED=false
COS_WATERMARK_TEXT=陈庆.我爱你
```

后台「CDN / 自定义域名」：**可清空且保存后不得被 env 错误回填中文域**。

### 6.4 展示水印（可选）

- `getSignedUrl(..., { watermark: true })` 拼数据万象 `watermark/2/text/<URL安全Base64>/...`，与 `imageMogr2` 可用 `|` 管道；参数签入签名  
- 图库 / 分享的 thumb 与图片详情预览可开；**管理端 `/api/sign` 原图下载不加**  
- **无法防录屏或截图**，仅作轻度版权提示

## 7. 分阶段落地（建议顺序）

| 阶段 | 内容 | 预期效果 |
|------|------|----------|
| P0 | 网格只用 thumb；详情先 thumb 后原图 | 图片列表明显加快 |
| P0 | 上传写入 poster；gallery 用海报 | 视频不再长期灰块 |
| P1 | 校正签名处理参数与 CORS | 减少加载失败 |
| P2 | 英文 CDN + 私有回源 + 长缓存 | 跨地区访问变快 |
| P2 | 视频 Range / 分片回源 | 起播与拖动更顺 |
| P3 | 工作流批量补封面、URL 预热 | 存量与高峰优化 |
| P3 | （可选）720p 预览转码，原片另存 | 大视频在线观看加速 |

## 8. 验收标准

- [ ] 打开图库：缩略图快速出现，无明显整页长时间空白  
- [ ] 图片格：Network 中为小体积 webp/jpeg，而非数 MB 原图  
- [ ] 视频格：有封面图；失败时有占位图标而非空框  
- [ ] 点开图片：先有模糊/小图，再过渡到清晰原图  
- [ ] 点开视频：可见封面并较快起播（允许默认静音）  
- [ ] 上传仍成功；PUT 主机为 `cos.<region>.myqcloud.com`  
- [ ] CDN 域为空或为英文域时，中文站名仅用于网页

## 9. 费用与风险（简要）

| 项目 | 说明 |
|------|------|
| COS 存储 | 原片容量费用，个人 20GB 量级通常很低 |
| COS 外网下行 | 无 CDN 时用户直连 COS 出流量，单价偏高 |
| CDN 流量 | 适合有观看量的分发；建议用量封顶 |
| CI 处理 | 缩略、截帧按次/用量计费 |
| 风险 | 签名过长泄露、公有读、中文域误作 CDN、列表拉原视频 |

## 11. 一句话总结

**原片无损进私有 COS；列表只看 CI 缩略图与截帧封面；能上英文 CDN 就上并长缓存；上传永远打 COS 源站。**  
按此做，图库才能稳定接近「秒加载」，而不是靠加大服务器带宽硬扛原片。
