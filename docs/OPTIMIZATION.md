## 已完成能力（可立即使用）

1. **管理后台** — `/admin` 液态玻璃侧边栏：仪表盘、上传、相册、媒体库、分享
2. **分享全链路** — 创建（密码/有效期）→ 列表/复制/删除 → `/share/[token]` 访问
3. **前台浏览** — `/` 时间轴、`/albums` 相册、灯箱、签名并发控制
4. **上传** — 预签名直传、拖拽、粘贴截图、归属相册、失败重试
5. **媒体批量** — `POST /api/media/batch` 移入相册 / 删除（可选 COS）
6. **统计** — `GET /api/stats`：媒体/相册/分享/体积
