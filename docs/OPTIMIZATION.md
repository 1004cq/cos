## 一、安全性

### 已完成
- [x] 强制签名访问接口 `GET /api/sign`
- [x] key 必须 `media/` 前缀
- [x] 上传预签名默认 5 分钟
- [x] 访问预签名默认 30 分钟，最大 1 小时
- [x] 相册 CRUD API
- [x] 分享链接创建（支持密码 + 过期）

### 待做
1. **STS 临时密钥**
   - 用 STS 换取短时凭证，再生成预签名
   - 永久密钥仅留在服务端换票，不直接签名
2. **上传限制 Content-Length**
   - 预签名时绑定文件大小，防止超大文件滥用
3. **分享访问接口**
   - `GET /api/share/[token]` 校验密码与过期后返回媒体列表 + 签名 URL
4. **操作日志表**
   - 记录上传、删除、分享、登录等关键操作

---

## 二、成本与性能

1. **数据万象（CI）缩略图**
   - 原图仍无损保存在 COS
   - 列表页用 `?imageMogr2/thumbnail/400x` 或 WebP 样式
   - 灯箱可切换「预览 / 原图」
2. **CDN 缓存**
   - 签名 URL 本身带时效，注意 Cache-Control 不要设过长
   - 缩略图可适当缓存，原图短缓存或不缓存
3. **生命周期**（见 README 第九章）
   - `media/` 90 天 → 低频
   - 分块上传碎片 7 天删除

## 三、用户体验

1. **灯箱 Lightbox**

2. **上传增强**
   - 粘贴上传（Ctrl+V）

3. **时间轴首页**
   - 按拍摄时间/上传时间倒序网格
   - 按月分组标题
4. **移动端**
   - 完整响应式
   - 底部安全区、触控热区
