## STS 说明

- `POST /api/upload/presign`：优先用 STS 临时密钥签 PUT，失败回退永久密钥
- `POST /api/upload/sts`：下发仅 `media/*` 上传权限的临时凭证（供客户端 SDK/分片）
- `COS_STS_ENABLED=0` 可关闭 STS
- 主账号密钥需具备 `sts:GetFederationToken` 权限

## 缩略图说明

- `GET /api/sign?key=...&thumb=1`：数据万象 `imageMogr2/thumbnail/{w}x{w}>/format/webp`
- 列表/封面用缩略图；灯箱按需拉原图
- 需在 COS 桶开通**图片处理 / 数据万象**；未开通时缩略 URL 可能 4xx，可暂关 thumb 或开通服务
- `COS_THUMB_WIDTH` 默认 480
